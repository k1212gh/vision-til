# 03. 객체 탐지 (YOLO) — "화면 어디에 고양이가 있는가"

## 왜 이걸 하나
2강의 움직임 감지는 "뭔가 움직였다"까지만 알려줍니다. **그게 고양이인지, 사람인지, 드론인지**는 모릅니다.
객체 탐지(object detection)는 프레임 안의 물체마다 **박스 + 이름 + 확신도**를 뽑아 줍니다.
이게 돔 시스템의 눈입니다. 고양이 위치를 알아야 드론을 보내고, 사람이 들어오면 드론을 멈추고, 드론끼리 부딪히지 않게 합니다.

## 핵심 개념

### 1. 탐지 결과의 형식
프레임 한 장 → 리스트. 항목마다:
| 필드 | 뜻 | 예 |
|---|---|---|
| xyxy | 박스 좌상단·우하단 픽셀 좌표 | (412, 200, 690, 480) |
| conf | 신뢰도 0~1. "이게 정말 그 물체일 확률" | 0.87 |
| cls | 클래스 번호 | 15 = cat |

2강의 컨투어 박스 (x, y, w, h)와 형식만 다를 뿐 같은 "박스"입니다. 4강 추적기가 이 박스들을 입력으로 받습니다.

### 2. COCO 80 클래스
기본 YOLO는 COCO라는 데이터셋(80종 일상 물체)으로 학습되어 있습니다.
**cat(15), dog(16), person(0), bird(14)** 가 이미 들어 있어서 추가 학습 없이 고양이를 찾습니다.
드론은 COCO에 없습니다. 나중에 우리 드론 사진으로 **파인튜닝**(추가 학습)해야 하고, 그게 이 강의 후반 주제입니다.

### 3. 신뢰도 임계값 (conf)
0.4면 "40% 미만 확신은 버림". 낮추면 놓치는 게 줄지만 오탐(엉뚱한 걸 고양이로)이 늘고, 올리면 반대.
돔에서는 "고양이를 놓치는 것"과 "없는 고양이를 보는 것" 중 어느 쪽이 더 나쁜지에 따라 정합니다.
(드론이 없는 고양이를 쫓아가는 것보다, 있는 고양이를 못 보고 부딪히는 게 더 나쁨 → conf를 낮게, 대신 4강 추적으로 오탐을 걸러냄)

### 4. 모델 크기와 속도
| 모델 | 파라미터 | GPU ms (참고) | 언제 |
|---|---|---|---|
| yolo11n | 2.6M | ~10 | 카메라 많을 때, 엣지 장비 |
| yolo11s | 9.4M | ~15 | 균형 |
| yolo11m | 20M | ~25 | 정확도 우선 |

이 PC(RTX 4070 SUPER) 실측: yolo11n 640px 기준 GPU 약 10ms, CPU 약 28ms.
30fps = 33ms 예산이니 GPU로는 카메라 3대분, CPU로는 1대분입니다. 카메라 30대면 이걸로는 부족하고, 그래서 **03-2 움직임 게이트**가 필요합니다.

### 5. NMS (non-max suppression)
신경망은 같은 고양이에 박스를 여러 개 겹쳐 내놓습니다. NMS가 겹치는 박스 중 신뢰도 최고만 남깁니다.
`model.predict()` 안에서 자동으로 되지만, "박스가 두 개로 갈라진다" 같은 현상을 볼 때 이걸 떠올리면 됩니다.

### 6. 움직임 게이트 (03-2)
```
프레임 → MOG2 움직임 % ──(≥ 0.5%)──► YOLO 실행 → 박스 갱신
                      └─(< 0.5%)──► 직전 박스 재사용  (30프레임마다 한 번은 강제 실행)
```
게이트 연산은 약 1ms, YOLO는 약 10ms. 정지 화면이 대부분인 돔에서는 YOLO 호출을 70~90% 줄일 수 있습니다.
화면에 "N/M frames (xx% skipped)"로 절약률이 나옵니다.

## 과제
1. 01: `g` 키로 GPU/CPU 전환하며 ms 차이 기록. `--model s` 와 `n` 의 ms 차이도 기록
2. 01: 폰에 고양이 사진을 띄워 카메라에 비추고, conf 를 `-` 로 내리면서 몇에서 오탐이 시작되는지 관찰
3. 02: 가만히 앉아 있을 때와 계속 움직일 때 "skipped %" 비교. `--motion 2.0` 으로 올리면?
4. (생각) 게이트가 놓치는 상황은? (힌트: 고양이가 아주 천천히 움직이면, 조명이 서서히 바뀌면, 카메라가 흔들리면)
5. (생각) 돔 카메라 30대 × 30fps 를 GPU 한 장으로 처리하려면 프레임당 몇 ms 안에 끝나야 하나? 게이트로 80%를 거르면?
