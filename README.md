# 비전 & 자동화 학습 로드맵 — 고양이 돔 프로젝트

> 최종 목표: 1000평 돔 안에서 고양이 ↔ 드론/자동장치 상호작용을
> 사용자에게 송출하고, 사용자가 원격으로 기기를 조작해 고양이와 놀 수 있는 시스템.

최종 시스템을 기술 블록으로 쪼개면 아래와 같고, 각 블록이 곧 학습 단계입니다.

```
[카메라 N대] → [영상 수집] → [고양이 탐지/추적] → [돔 좌표계로 변환]
                                    ↓                       ↓
                            [사용자 송출(스트리밍)]   [기기 제어(드론/로봇)]
                                    ↑                       ↑
                            [사용자 조작 입력] ─────────────┘
```

| 단계 | 주제 | 최종 시스템에서의 역할 | 상태 |
|---|---|---|---|
| 01 | 카메라 연결 & 영상의 정체 | 돔 안 카메라 수십 대에서 영상을 받아오는 기초 | 코드 완성, 폰 실측 남음 |
| 02 | OpenCV 영상처리 기초 | 색공간, 필터, 움직임 감지 (고양이가 움직였나?) | 진행 중 |
| 03 | 객체 탐지 (YOLO) | 화면 어디에 고양이가 있는가 | 진행 중 |
| 04 | 객체 추적 (ByteTrack 등) | 고양이 A/B/C를 시간에 따라 구분해 따라가기 | |
| 05 | 카메라 캘리브레이션 & 다중 카메라 | 픽셀 좌표 → 돔 실제 좌표(m) 변환, 카메라 간 인계 | |
| 06 | 스트리밍 (RTSP / WebRTC) | 사용자 앱으로 저지연 송출 | |
| 07 | 기기 제어 & 자동화 | 드론/로봇 SDK, "고양이 쪽으로 이동" 피드백 루프 | |
| 08 | 통합 & 운영 | 여러 블록을 묶고, 안전장치(고양이 근접 시 정지 등) | |

## 진행 방식
1. 개념·아키텍처 설명 (왜 필요한지, 최종 시스템과 어떻게 연결되는지)
2. 완성된 예제 코드를 **읽고 실행하며** 이해 (각 NN_주제 폴더, 주석이 곧 교재)
3. 과제로 코드를 직접 바꿔 보기 → 막히면 질문
4. 매일 [til/](til/) 에 기록하고 커밋
