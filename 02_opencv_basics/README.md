## 핵심 개념

### 1. 색공간 (color space) — 같은 픽셀을 다른 숫자로
| 색공간 | 채널 | 언제 쓰나 |
|---|---|---|
| BGR | 파랑, 초록, 빨강 | OpenCV 기본. 화면 표시용 |
| Gray | 밝기 1채널 | 움직임·엣지·차분 등 "색이 필요 없는" 연산. 데이터 1/3, 속도 3배 |
| HSV | 색상(Hue), 채도, 명도 | "빨간 것만" 같은 **색 기준 선택**. 조명이 바뀌어도 H는 비교적 안정 |

OpenCV의 H는 0~179 (360도를 반으로). 빨강은 0 근처와 170 근처 양쪽에 걸림.

### 2. 블러 (blur) — 노이즈 죽이기
카메라 센서는 가만히 있어도 픽셀값이 ±몇씩 흔들립니다. 그대로 차분하면 온 화면이 "움직임"으로 나옵니다.
GaussianBlur로 뭉개서 작은 흔들림을 없앤 뒤 비교합니다. 커널이 클수록 둔감해짐.

### 3. 움직임 감지 두 방식
| 방식 | 원리 | 장점 | 단점 |
|---|---|---|---|
| 프레임 차분 | 이전과 현재의 절대 차이 | 단순, 빠름, 즉시 반응 | 멈춘 물체는 사라짐. 조명 변화·카메라 흔들림에 약함 |
| 배경 차분 (MOG2) | 픽셀마다 "배경 분포"를 학습, 벗어나면 전경 | 천천히 변하는 조명 적응. 그림자 분리 | 학습 시간 필요. 오래 멈춘 물체는 배경에 흡수됨 |

돔에서는 배경(바닥, 캣타워)이 고정이고 고양이가 움직이므로 MOG2가 기본, 프레임 차분은 보조.

### 4. 임계값 (threshold) → 이진 마스크
"차이가 25 이상이면 255(움직임), 아니면 0". 결과가 흑백 마스크. 임계값을 올리면 둔감, 내리면 민감.

### 5. 모폴로지 (morphology) — 마스크 다듬기
- 열기(open): 작은 흰 점 제거 (침식→팽창)
- 닫기(close): 덩어리 안 검은 구멍 메우기 (팽창→침식)
- 팽창(dilate): 덩어리를 키워 조각난 부분을 하나로

### 6. 컨투어 (contour) → 바운딩 박스
마스크에서 흰 덩어리의 외곽선을 찾고, 면적이 작은 건 버리고, 남은 것의 (x, y, w, h)를 구합니다.
이 박스가 3강 YOLO 박스와 같은 형식이라 뒤 단계에 그대로 넘길 수 있습니다.
